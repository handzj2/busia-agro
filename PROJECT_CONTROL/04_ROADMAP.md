ROADMAP
=======

PHASE 0 — Foundation (Complete)
-------------------------------

- Next.js 14 + TypeScript + Tailwind project setup
- Core layout, navigation, footer
- Design tokens and Product DNA established
- Content data shapes defined in `lib/types.ts`
- Static pages structure


PHASE 1 — Core Website (V1) — CURRENT
-------------------------------------

Objective: Launch a credible professional website.

Deliverables:
- All public pages functional
- Real client content replacing placeholders
- Working contact paths (phone, WhatsApp, form)
- Real photos where available
- Production deployment

Status: In progress — content readiness + control system


PHASE 2 — Self-service Website (V2)
-----------------------------------

Objective: Client can publish and update content without a developer.

Planned:
- Authenticated `/admin` area
- PostgreSQL database (see `docs/DATABASE_SCHEMA.md`)
- CRUD for Products, Projects, Field Activities, News
- Media manager
- Contact message inbox
- Same public-facing design language preserved


PHASE 3 — Business Platform (V3)
--------------------------------

Objective: Support tender, funding, and partnership workflows.

Planned:
- Tender / opportunity management
- Funding and partnership information
- Document management
- Basic reporting


PHASE 4 — Commerce / Operations (Conditional)
---------------------------------------------

Only if the business model requires it:
- Enquiries → orders → inventory → payments → invoicing

Not assumed. Requires explicit business decision.


FUTURE / UNAPPROVED
-------------------

Anything not listed above stays here until it passes the scope gate:

IDEA → BUSINESS VALUE → USER NEED → SCOPE REVIEW → ROADMAP → APPROVAL
