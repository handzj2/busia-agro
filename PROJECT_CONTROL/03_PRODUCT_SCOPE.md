PRODUCT SCOPE
=============

IN SCOPE — V1 (Current)
-----------------------

Pages:
- Home
- About
- Services
- Products (catalogue by category + detail pages)
- Field Activities (list + detail pages)
- Projects (list + detail pages)
- Contact (form + map + contact details)

Features:
- Static content driven from `/content/*.ts`
- Responsive layout (mobile-first)
- WhatsApp floating button + primary CTAs
- Theme toggle (light/dark consideration already present)
- Formspree-ready contact form
- SEO-friendly structure (Next.js App Router)

Content types:
- Company profile
- Services
- Product categories & products
- Field activities (dated records)
- Projects (portfolio records)


OUT OF SCOPE — V1
-----------------

- Any form of authentication or admin UI
- Database, API routes for content, or CMS
- Online cart, checkout, or payments
- User accounts or order history
- Tender / opportunity management
- Document upload or media library management
- Multi-language
- Advanced analytics or tracking (unless explicitly requested)
- Invented features, services, or statistics not confirmed by the client


SCOPE RULES
-----------

1. New features must be proposed, reviewed against the roadmap, and approved before implementation.
2. Content changes that invent unverified claims (impact numbers, certifications, services) are out of scope until client confirmation.
3. Visual changes that introduce generic SaaS patterns are out of scope (see Product DNA).
4. Architecture changes that break the V2 migration path described in BLUEPRINT.md require explicit approval.
